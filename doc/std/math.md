# math

`math.sin(x)` returns the sine of an angle in radians.

- `x`: angle in radians

`math.cos(x)` returns the cosine of an angle in radians.

- `x`: angle in radians

`math.tan(x)` returns the tangent of an angle in radians.

- `x`: angle in radians

`math.asin(x)` returns the angle in radians whose sine is the given value.

`math.acos(x)` returns the angle in radians whose cosine is the given value.

`math.atan(x)` returns the angle in radians whose tangent is the given value.

`math.sinh(x)` returns the hyperbolic sine of a number.

`math.cosh(x)` returns the hyperbolic cosine of a number.

`math.tanh(x)` returns the hyperbolic tangent of a number.

`math.floor(x)` returns the largest whole number that is not greater than the value.

`math.ceil(x)` returns the smallest whole number that is not less than the value.

`math.round(x)` returns the nearest whole number, rounding halves away from zero.

`math.exp(x)` returns e raised to the given power.

`math.log(x)` returns the natural logarithm of a number.

`math.log10(x)` returns the base-10 logarithm of a number.

`math.sqrt(x)` returns the square root of a number, which is NaN for negative values.

`math.abs(x)` returns the absolute value of a number.

`math.min(a, b)` returns the smaller of two numbers.

`math.max(a, b)` returns the larger of two numbers.

`math.pow(a, b)` returns a raised to the power b.

`math.mod(a, b)` returns the remainder of dividing a by b, taking the sign of a.

`math.clamp(x, min, max)` restricts x to the inclusive range between min and max.

`math.lerp(a, b, t)` linearly interpolates from a to b, where t of 0 gives a and 1 gives b.

`math.sign(x)` returns -1, 0 or 1 according to the sign of the value.

`math.isnan(x)` returns true when the value is NaN.

`math.isfinite(x)` returns true when the value is neither infinite nor NaN.

`math.deg(radians)` converts an angle from radians to degrees.

`math.rad(degrees)` converts an angle from degrees to radians.

`math.random()` returns a uniformly distributed random number in the range [0, 1).

`math.randomInt(min, max)` returns a uniformly distributed whole number between min and max, inclusive.

`math.seed(n)` seeds the random generator from n so later values are reproducible, returning nothing.
